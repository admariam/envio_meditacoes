Meditações diárias no WhatsApp

Preparação, validação e exportação da configuração usada pelo envio diário via Baileys.

Integração não oficial. Este projeto usa @whiskeysockets/baileys, não a API oficial do WhatsApp. Mudanças no WhatsApp podem interromper o funcionamento, e o uso de automação pode restringir a conta. Não há garantia de disponibilidade contínua.
Esta página é pública e estática. Ela não acessa o repositório privado, não envia mensagens, não usa localStorage e não salva nada no navegador. A configuração privada deve ser mantida em um repositório GitHub privado e atualizada manualmente com os arquivos exportados aqui. Sem um backend autenticado, o Pages não consegue ler nem alterar esses dados com segurança.

    Limitações importantes
    
        
      
          
    • O GitHub Actions não garante início no minuto exato; filas e manutenção podem atrasar a execução.
      • 
          
    • Em repositórios públicos, workflows agendados podem ser desativados após 60 dias sem atividade no repositório.
      • 
          
    • A interface não edita o repositório privado. A atualização é manual, por exportação e envio dos arquivos.
      • 
          
    • Baileys é não oficial: o WhatsApp pode alterar o protocolo, limitar ou restringir a conta.
      • 
          
    • O envio é tentado uma vez por grupo/dia; falhas exigem nova tentativa manual controlada.
